## What the drill found

1. **A cache outage was a full outage** (run 1). The Lambda logs: cache warm-up during
   init failed after ~3 s (1 s connect timeout per endpoint IP), the request spent another
   ~3 s on `get`, started `set` and hit the 6 s timeout. A timeout resets the execution
   environment, so the next request was a cold start that tried again. The design said
   "the cache degrades to DynamoDB"; the unit tests' fake cache failed instantly, so they
   never saw the time it takes to *fail*. Fix: a circuit breaker (skip the cache for 30 s
   after a failure, count each skip as a valkey error). Run 2 served every request.
2. **A dependency that fails fast was refuted by its latency share.** In run 2 valkey had 8
   errors at 1.5 ms, and the "scale" check (is it a big enough share of the API's p95?)
   refuted it. Errors now decide when there are errors. The analysis below is run 2's
   evidence re-run with that fix (offline, same evidence); the run itself showed valkey
   refuted, H1 and the action unchanged.
3. **The explanation parser said "blocked at None"** in run 1; the analyzer names the
   group in `SecurityGroups` (a list). Fixed before run 2.
4. **Not fixed, said plainly:** vendor-recs is "confirmed" in both runs from a single cold
   call against an *expected* baseline (no history). The root-cause rule still picks
   `network`, but the hypothesis list is noisier than it should be (WAITING item G3).

### Recommended (for a human, through the pipeline): `reapply-shared-stack` (for H1)

A security group, route or NACL in the env's shared network drifted from Terraform (changed by hand). Re-apply the stack through the pipeline; the plan shows exactly what it restores.

- **Lane:** change: Terraform through CI, not executed by this loop.
- **How:** `gh workflow run apply.yml --ref main   # re-plans and re-applies every dev stack; shared/<env> restores the rule`
- **Blast radius:** The env's shared network and cache (all its customers) return to what Terraform declares. Nothing else changes.
- **Rollback:** None needed (it restores the declared state); to keep the hand change, make it a PR instead.
